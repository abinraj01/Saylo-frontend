# Saylo Frontend

Frontend application for **Saylo**, a real-time messaging application built with React and Vite.

## Tech Stack

- React
- Vite
- Material UI
- Axios
- Socket.IO Client
- JavaScript

## Features

- User registration and login
- User authentication
- Protected routes
- Real-time messaging
- Typing indicators
- Message editing and updates
- Responsive messaging interface
- REST API integration
- Real-time communication using Socket.IO
